## 0.1.0

- Initial Kotlin/JS Compose HTML component library.

- Added high-level component APIs for actions, data display, feedback, forms,
  layout, mockups, and navigation.
- Added Tailwind CSS 4 and daisyUI 5 Webpack bridge for Gradle-managed Kotlin/JS
  apps.
- Added demo app with theme switching and a one-screen product landing page.
